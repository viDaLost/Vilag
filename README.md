# Империя Великой Реки — 3D RTS

Полноценная браузерная стратегия в реальном времени на Three.js. Игра запускается как статический сайт, не зависит от CDN, сохраняет кампанию в браузере и адаптируется под телефон, планшет и ПК.

## Игровой цикл

Кампания «Клятва Великой Реки» состоит из четырёх последовательных глав:

1. **Долина** — запустить ферму, лесопилку и шахту, создать запас пищи и увеличить поселение.
2. **Рубеж** — построить оборону, собрать постоянное войско и уничтожить первый лагерь.
3. **Золотой путь** — развить технологии, торговую сеть и престиж.
4. **Наследие** — выбрать победу через Чудо света или полное уничтожение лагерей.

Проигрыш наступает при разрушении столицы. После победы мир можно продолжать развивать.

## Системы игры

- детерминированная карта с seed: река, три брода, озеро, леса, плодородные зоны, холмы, скалы и священные места;
- конечные лесные и каменные ресурсы с восстановлением;
- рабочие с назначениями, приоритетами зданий, добычей, доставкой и бегством от врагов;
- дружеские воины с построением, патрулём, поиском целей и автоматическим боем;
- вражеские лагеря со складами, гарнизонами, фазами охраны, набега, отступления и лечения;
- навигация A* с обходом воды и зданий, использованием бродов и ускорением на дорогах;
- автоматическая сеть дорог, усиливающая рынки, порты и движение;
- строительство, очередь обучения, улучшение, ремонт, снос, точки сбора и рабочие приоритеты;
- шесть исследований, три эпохи, погода, смена дня и ночи;
- две ветки победы и последовательные награды кампании;
- версионное автосохранение всего мира: здания, очереди, NPC, задания, ресурсы и лагеря;
- PWA/service worker для повторного запуска без сети после первой загрузки.

## Управление

### Телефон и планшет

- касание — выбрать землю, здание, ресурс или юнита;
- движение одним пальцем — переместить камеру;
- жест двумя пальцами — масштаб и угол камеры;
- касание миникарты — перейти в нужную область;
- нижняя панель — строительство, войска, исследования, армия, скорость и меню.

### ПК

- левый клик — взаимодействие;
- правая кнопка и движение — вращение камеры;
- колесо — масштаб;
- кнопка «Армия» — выбрать всех воинов, затем указать точку построения.

## Запуск

Игра не требует сборки. Нужен любой статический HTTP-сервер:

```bash
npm install
npm run serve
```

Откройте `http://localhost:8080`. Простое открытие `index.html` через `file://` не рекомендуется из-за ограничений ES-модулей браузера.

## Проверка

```bash
npm test
```

Команда запускает ESLint и набор тестов игровой логики. Дополнительно в `tests/` находятся:

- `e2e.mjs` — браузерная проверка запуска, строительства, обучения, сохранения/восстановления и мобильной компоновки;
- `runtime-audit.mjs` — аудит ошибок, загрузки, WebGL и размеров интерфейса для ПК, телефона и планшета;
- `soak.mjs` — ускоренная трёхминутная симуляция экономики и вражеского ИИ.

Для браузерных тестов задайте `CHROMIUM_PATH` и запустите локальный сервер на порту `8765`.

## Размещение

Репозиторий готов к GitHub Pages через `.github/workflows/deploy-pages.yml`. Один раз выберите **GitHub Actions** в **Settings → Pages → Build and deployment → Source**. После этого каждый push в `main` запускает тесты, формирует чистый статический артефакт и публикует игру. Все зависимости Three.js и simplex-noise находятся в `vendor/`, поэтому внешние CDN не нужны.

## Структура

- `src/core/` — сцена, ввод, загрузка моделей, адаптивная производительность;
- `src/systems/` — карта, ресурсы, дороги, навигация, экономика, здания, NPC, бой, события, сохранение;
- `src/ui/` — HUD, нижние панели, миникарта, окна и выбор объектов;
- `assets/` — модели зданий, юнитов и окружения;
- `vendor/` — локальные браузерные зависимости;
- `tests/` — логические, браузерные и длительные проверки.
